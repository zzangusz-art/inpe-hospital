# 병원 실측 신청 DB 연결 — 설정 가이드 (10분)

홈페이지 신청서 → **구글 시트에 한 줄씩 저장** → **메일 알림**(선택: 슬랙)까지 연결합니다.
비용 없음. 회사 공용 구글 계정으로 진행하세요.

> 인프케어(반려동물) 사이트와 **다른 시트, 다른 웹앱**으로 받으세요. 항목(기관명·병상 수 등)이 달라 한 시트에 섞으면 열이 어긋납니다.

## 1. 시트 만들기
1. 구글 드라이브 → 새로 만들기 → 구글 스프레드시트 → 이름 `인프 병원청소 실측 DB`
2. 상단 메뉴 **확장 프로그램 → Apps Script**
3. 기본 코드를 모두 지우고 `Code.gs` 내용을 붙여넣기
4. 맨 위 `NOTIFY_TO` 에 알림 받을 메일 주소 입력 (여러 명이면 쉼표)
5. 저장(💾)

## 2. 권한 승인
1. 함수 선택에서 `setup` 선택 → **실행**
2. "승인 필요" → 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용
   (본인 스크립트라 뜨는 표준 경고입니다. 시트·메일·드라이브 권한을 요청합니다.)
3. 시트에 `병원 실측신청` 탭이 생기면 성공
4. `testPost` 실행 → 시트에 테스트 1줄(테스트병원) + 알림 메일 1통 오는지 확인 → 테스트 행은 삭제

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → 유형 **웹 앱**
3. 실행 계정: **나**  /  액세스 권한: **모든 사용자**
4. 배포 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`) 복사

## 4. 홈페이지에 연결
`assets/js/config.js` 의 `LEAD_ENDPOINT: ''` 따옴표 안에 3번 URL을 붙여넣고 저장 → 업로드.

## 5. 실제 점검 (꼭 하세요)
1. 휴대폰으로 홈페이지 접속 → 무료 실측 신청 → 사진 1장 첨부해서 제출
2. ✅ 완료 창에 접수번호(**IH**로 시작)가 뜨는지
3. ✅ 시트에 행이 생기고 기관명·기관 유형·면적·작업 가능 시간이 제자리에 들어갔는지, 사진 링크가 열리는지
4. ✅ 알림 메일이 왔는지 (담당자가 이메일을 적었다면 메일에서 바로 '답장'하면 담당자에게 갑니다)

화면에 "접수되었습니다"가 떠도 **시트에 행이 생긴 것까지 확인**해야 진짜 연결된 것입니다.

## 운영 방법
- **상태(C열)**: `접수 → 상담 중 → 실측 예정 → 견적 발송 → 계약 / 보류 / 취소`
- **연간 예상금액(T열)**: 견적 계산기를 거쳐 신청한 경우에만 들어갑니다. 계산기 기준 참고값이라 실제 견적과 다를 수 있습니다.
- 광고 유입 분석: V열부터 utm·네이버 검색어(n_query)·gclid·첫 랜딩 페이지가 저장됩니다.
- 실시간 접수 현황은 기관 고객이라 **홈페이지에 띄우지 않도록 꺼 두었습니다** (`config.js` 의 `LIVE_FEED: false`).
- 메일 한도: 일반 구글 계정 하루 100통 (초과 시에도 시트 저장은 정상).

## 슬랙 알림 (선택)
1. 슬랙에서 **새 Incoming Webhook URL** 발급
2. Apps Script 왼쪽 **프로젝트 설정 → 스크립트 속성 → 속성 추가**: 이름 `SLACK_WEBHOOK`, 값 = 웹훅 URL
3. URL은 서버(스크립트 속성)에만 있으므로 홈페이지 코드에 노출되지 않습니다.

## 코드를 고친 뒤
**배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포** (URL이 바뀌지 않음). '새 배포'를 다시 만들면 URL이 바뀌니 주의.
